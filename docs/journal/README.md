# Journal & Evaluations

Weekly journal entries and evaluation worksheets from the Modeling Motion course at Evergreen State College (Winter/Spring 2004).

These documents chronicle my learning journey through physics, calculus, and programming — including the development of the Rubik's cube program that became my signature project.
