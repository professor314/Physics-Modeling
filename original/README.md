# Original Code (2004)

All code in this directory was written during the Modeling Motion program at The Evergreen State College in 2004. The only modifications made are minimal Python 3 syntax fixes (marked with `# Python 3 fix` comments) to allow execution on modern Python interpreters.

No logic, algorithms, variable names, or coding style has been altered.

---

## rubiks-cube/

My independent project — a 3D Rubik's cube built from scratch using VPython. Contains every version from early experiments to the final working implementation.

**Key files:**
- `best_cube.py` — Most complete version with all rotations working
- `cube_class.py` — Object-oriented refactor with class structure
- `cube_functions.py` — Extracted rotation functions
- `cube(all turning works!).py` — The breakthrough version where all face rotations finally worked
- `cube breakthrough!.py` — Another milestone version
- Various `cube*.py` files — Intermediate experiments and iterations

## assignments/

Course assignments — physics simulations written as part of the class curriculum.

| File | Description |
|------|-------------|
| `spring.py` | Spring pendulum class (CompositeObject, Spring, SpringPendulum) with Euler's method |
| `springsim.py` | Simulation runner for the spring pendulum — creates visualization and animation loop |
| `universe.py` | Ball and Universe classes — gravity, boundary collisions, extensible physics engine |
| `fountain.py` | Particle fountain using the Universe framework — launches colored balls with gravity |
| `collision.py` | Billiard ball collision simulation using elastic collision physics |
| `sir.py` | SIR epidemic model — susceptible/infected/recovered with difference equations |
| `logistic.py` | Logistic equation with multiple step-size curves plotted together |
| `lissajous.py` | 3D Lissajous figure drawn as a colorful helical curve |
| `lissa2.py` | Variant Lissajous implementation |
| `riemann.py` | Numerical integration using Riemann sums |
| `graph-sir.py` | SIR model with graphical output |
| `aviary.py` | Bird class — object-oriented programming exercise |
| `Bird Test.py` | Test driver for the Bird/aviary classes |
| `week4.py` | Week 4 assignment |
